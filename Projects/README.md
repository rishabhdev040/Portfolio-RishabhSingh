# Projects

This directory contains standalone implementations showcased in the portfolio repository.

## Projects

- [Pills Counter & Image Preprocessor](./pills-counter/) — YOLOv8 pill detection and counting experiments, plus a Streamlit interface for JPG preprocessing with drag-and-drop uploads, progress tracking, and logs.
- [Customer Segmentation](./customer-segmentation/) — customer behavior exploration and five-cluster K-Means model with a Streamlit prediction app.
- [Handwritten Digit Recognition](./handwritten-digit-recognition/) — handwritten digit classification using a custom CNN.
- [MCP Tool Server](./mcp-tool-server/) — Model Context Protocol server enabling LLM agents to interface with external tools and resources with Pydantic schema validation.
- [PDF Chatbot](./pdf-chatbot/) — AI-powered PDF Q&A chatbot using LangChain, OpenAI, ChromaDB, RAG, and Streamlit.
- [Sentiment Analysis API](./sentiment-analysis/) — three-class feedback classification with Hugging Face Transformers, Pydantic validation, and FastAPI.
